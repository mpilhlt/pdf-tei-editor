Backfill Missing Metadata

Adds missing bibliographic data and the document language to all documents in collection __COLLECTION__. Existing values are never overwritten. Metadata comes from CrossRef/DataCite if a DOI is known, otherwise from GROBID header extraction if available; the language is predicted from the text if the registry does not provide it.

Only report what would be added, without saving anything.
Extract header metadata with GROBID for documents without DOI, if the GROBID server is available.
Save a JSON report with the added fields and values of each document when the run is finished.
