# Plugins page in the user manual

Christian asked to integrate plugin documentation into the user manual, with a link to the plugin overview at <https://mpilhlt.github.io/pte-plugins/>.

## Changes

- `docs/user-manual/plugins.md`: where plugins appear in the interface, where their documentation is (plugin overview, README buttons in the Plugin Manager), which plugins are installed. Reuses the Tools menu screenshot `docs/images/admin-tools-menu.png`.
- `docs/index.md`: entry in the User Manual list.
- `docs/user-manual/interface-overview.md`: link from "Added by Plugins".

## Follow-up

Contributing documentation such as tutorials from installed plugins into the manual (e.g. a tutorial on the LLM Reviewer with GROBID, shown only if both plugins are installed) is proposed in a separate GitHub issue.
